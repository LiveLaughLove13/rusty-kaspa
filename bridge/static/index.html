Use Prometheus (easiest path)

This dashboard only keeps short-lived session charts. For days or weeks of history, run Prometheus (and optionally Grafana) on your network and scrape the bridge below. Then use Explore or dashboards against your Prometheus—not this tab.

Open /metrics
Prometheus static_configs.targets should reach this URL (same host/port you use for this UI):
—
Example PromQL (paste into Prometheus or Grafana Explore) 
# Valid shares per second by worker
sum by (worker) (rate(ks_valid_share_counter[5m]))

# Network difficulty (instant)
ks_network_difficulty_gauge

# Estimated network hashrate
ks_estimated_network_hashrate_gauge

# Blocks mined per hour (approx., counter)
sum(rate(ks_blocks_mined[1h])) * 3600
