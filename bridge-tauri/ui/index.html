How to start the Stratum bridge

Run the bridge from this app: set global options below, then click Start bridge. The operator dashboard (bundled in this app) loads below the header. Use Stop bridge in the top bar when you are done (or Bridge → Stop bridge in the menu). If you reload the window (F5) while the bridge is still running, the app reconnects to the dashboard instead of showing only this setup screen.
